# Quiz is an interactive chat session, not a printable question sheet

Quiz asks one question at a time, waits for an answer, gives feedback, then continues — rather than generating a full worksheet upfront with a separate answer-key page, the way the original idea sketch described (matching the pattern used for summary/flashcards). That static, printable-upfront design was the realistic alternative, and is what's still used for summary/flashcards.

The interactive shape overlaps with what a separate, unbuilt idea (tutor-loop, in the personal idea sketches) was meant to own — cram-kit was meant to stay "static" — but immediate per-question feedback fits how material is actually crammed, and a printable recap (score + answer key) is still produced afterward.

**Consequences**: quiz can't be used non-interactively (e.g. "generate 10 questions and print them" isn't supported). Revisit if a print-first quiz mode is ever requested.
